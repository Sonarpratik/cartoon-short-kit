# Character references have moved

Project-owned designs, renderer snapshots and turnaround sheets now live in `projects/<project>/character-references/`. Flying Dutchman keeps `original/`, `v2/`, `motion-v3/` and `current/` versions inside its project.

The reusable catalog is [character-library/cast.json](../../character-library/cast.json), and reusable renderer snapshots are in `character-library/shared/`. Character Studio and the save/snapshot tools use these new locations.

User-supplied reference media belongs in [references/user-supplied/](../user-supplied/). The supplied pirate-cannonballs video and extracted study images are stored there; they are private study material.
