# Preserved style examples

These examples are independent of projects/mkultra. Deleting that project does not remove this folder.

- backgrounds-approved-v3.jpg: the user's preferred detailed-room and window-light direction.
- distinct-cast.png: hats, moustaches and different hair silhouettes.
- hair-reflection.jpg: curved glossy hair/headwear reflection.
- face-glow-outline.jpg: pearl face layer and thin/thick head ink.
- pointed-body-edge.jpg: narrow contour-following body reflection with pointed ends.
- camera-paths.jpg: original rendered examples of camera travel and parallax.

These are our rendered project examples, not extracted frames from the user's reference channel. The private reference frames live separately in ../lighting and ../camera-study. Keep those private.

Reusable detailed-room code is in ../../templates/interior. A source-only worked example is preserved in ../../templates/examples/interior-short-source.zip, excluding narration, output videos and private reference imagery.
