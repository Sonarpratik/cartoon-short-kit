# Cast v2 brief (ages, villains, monsters)
Read CAST_BRIEF.md FIRST: every rule there still applies (quality bar = sheet 01, one giant silhouette signature each, meme-level faces never repeated on a sheet, white skin, ink stick limbs, stay inside x = cx +/- 250, respect + no copyrighted characters, iterate with at least two review passes).
Also look at a few finished v1 sheets (out/sheet03.png, out/sheet11.png) so you don't repeat a character that already exists. Already in the cast: zombie, mummy, vampire, witch, wizard, mad scientist, alien, robot butler, fairy, superhero, cyber hacker, ninja, pirate captain, outlaw, gangster, clown, jester, plague doctor.

NEW BODY FORMS (bodies.mjs, look at out/bodies2_front.png): 'toddler' (between baby and kid, overalls), 'teen' (lanky hoodie, hands at the pocket), 'teengirl' (cropped jacket + pleated skirt, egg head + bob), 'brute' (tiny head, giant shoulders, knuckles nearly drag: henchmen, ogres, monsters), 'ghost' (no legs, floating bell sheet with wavy hem, arms up). Forms bring their own default details; set keepFormDetails: true to keep them, otherwise draw your own in details().

NEW FACE SETS: faces_teen.mjs (TEEN), faces_villain.mjs (VILLAIN), faces_monster.mjs (MONSTER). Use in a spec as face: ['teen', 'name'] etc. Board: node board3.mjs teen|villain|monster -> out/<set>_board.png.
Face contract (same as memes.mjs / memes2.mjs, read both for helpers and style): each face (cx, hy) => { skin?, rot?, sx?, sy?, under: [], over: [] } in head space (centre cx,hy, R = 100; the rig scales the head x1.5 and thins strokes). skin = a gradient id; built-in ids: sk, skRed, skBlue, skGreen, skShadow, skPale, skPink, skSepia. New gradients go in the set's <SET>_DEFS string with ids prefixed by the set name (e.g. monster_fur).
Faces must be EXTRA HUGE, meme-level, each its own drawing (not the same parts moved): features may break the head outline, head may tilt/squash, skin may change colour, add effect marks (sweat, steam, sparkles, speed lines, text like "MWAHAHA"). Keep any text INSIDE the 470x620 board cell and not over the eyes.

SAFETY FOR SHARED FILES: castkit.mjs imports memes3.mjs, which imports ALL three face files. A syntax error in a face file breaks every agent's render. So develop in a private draft (e.g. faces_villain_dev.mjs), check it with `node -e "import('./faces_villain_dev.mjs').then(m=>console.log(Object.keys(m.VILLAIN)))"`, and only then `cp` it over faces_villain.mjs (cp, never edit faces_*.mjs in place). Only touch YOUR face file and YOUR sheet file. Never edit char2d/castkit/bodies/memes/memes2/memes3/castsheet/board3.

FINAL REPLY: the PNG paths (face board + sheet), one line per face (name: what it shows), one line per character (label, form, face, silhouette signature), and any problem you couldn't solve.
