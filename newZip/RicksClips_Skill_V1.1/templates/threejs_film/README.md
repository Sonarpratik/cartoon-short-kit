# threejs_film: storyboard, animatic and layout lock from the baked plan

The film is planned once (`tools/film_plan.py check film.json` writes `out/plan/camera_baked.json` and `performance_baked.json`). This kit only PLAYS that plan: toon sets, the vector2d puppets as flat cards, one-word captions. It owns no timing and no camera maths.

```
node render.mjs <film.json> --storyboard      # out/storyboard.html + .png: START and END panel per station, CAM / MOVE / WORD strip
node render.mjs <film.json> --animatic        # out/animatic.mp4 at half size (voice/voice.wav is muxed when it exists)
node render.mjs <film.json> --frames 0,45     # out/stills/f_#####.png
node render.mjs <film.json> --visibility      # out/plan/visibility.json: where every character and prop sits in frame, per frame
node render.mjs <film.json> --export-lock     # out/lock/: what the Blender look pass reads (below)
node render.mjs <film.json> --serve           # watch it play in a browser
```

Options: `--scale 0.5`, `--no-captions`, `--card-px 2`, `--puppets <dir-or-file,...>`. Needs node 18+, playwright with its Chromium (`npm i playwright` then `npx playwright install chromium`, once) and ffmpeg on the PATH. Built and tested in the cloud session; not yet run on the PC. three.js r165 is in `vendor/`.

- **Files.** `film.js` + `film_page.html`: the player (`window.setup(cfg)`, `window.renderFrame(f)`). `render.mjs`: the command line. `puppets.mjs`: adapter to the character package (`stateKey`, `svgFor`). `poses.mjs`: pose library (hand targets, held props drawn at the hand). `sets/<name>.js`: one module per set.
- **Characters.** The package path is one value: `--puppets`, else env `PUPPET_PKG`, else film.json `"puppet_pkg"`, else the locked package `templates/vector2d_characters/code/` (the characters work owns it; this kit never edits it). It is copied to `out/.puppet_cache/` and never edited. Cast entry: `"puppet": "stationmaster"` (a name in cast.mjs) or `"form:<name>"` (a body form: kid, lady, elder, baby, ...), plus `"height"` in metres.
- **The cast (150 characters).** `"puppet": "cast:<name>"` plays any character from the cast sheets (`templates/vector2d_characters/code/sheets/sheetNN.mjs`; pictures in `sheets_png/`), or `"cast:sheet03/<name>"` when two sheets share a name (`queen` is on sheets 01, 03 and 14). The sheet gives the hat, hair, costume and held things; the film gives face, mouth, blink and pose. `"standard"` = the character's own face. With pose `stand` it keeps its own arms and props; a gesture pose redraws the arms, and a hand-held item then stays where the sheet drew it. Cast characters are drawn for the front view. Tested on `cast:pharaoh`, `cast:cowboy` and `cast:sheet03/queen` in the example film.
- **Sets.** `places.<name>.set` names `sets/<set>.js` (the episode's own `sets/` folder wins). It exports `build(THREE, scene, film, ctx)` and may return `{ update(f, t), anchors }`. Plan coordinates are metres, Z up; use `ctx.B2T([x, y, z])`. Give every mesh a `name` and `userData.role` (ground, wood, metal, cloth, glass, stone, brick, plaster, roof, water, foliage, lamp) or an exact `userData.mat = "wood_grain"`.
- **Poses.** Add a line to `POSES` in `poses.mjs`: a hand target `[out, down]` in arm lengths from the shoulder. An unknown pose warns and stands.
- **Lock format** (`out/lock/`, about 16 MB for the demo, 30 s to write):
  - `sets/<place>.glb`: the set only (no sky, lights, camera or cards), exported Y up as three.js has it. Blender's glTF importer turns glTF (x, y, z) into (x, -z, y), which is the plan's (x, y, z), so do not rotate it. Materials are named `mat:<library name>`, or `mat:<library name>.<rrggbb>` when a set uses one in several colours (read the name up to the first dot); untagged ones are `mat:untagged_<rrggbb>`. The colour is the base colour. Node extras carry `role`, `mat`, `color`. Moving set parts are in their frame 0 pose.
  - `cards/<who>/s0001.png ...`: one transparent drawing per unique drawn state, 1600 x 3000. `cards/<who>/index.json`: `{ who, puppet, px: [w, h], ground_px, centre_px, height_m, metres_per_px, images: [{ img, file, keys }], runs: [{ f0, f1, img, pos: [x, y, z], flip, visible }] }`. `img` is 1-based, `pos` is where the soles stand (plan coordinates), the image is centred on `pos` in x, and the card turns to the camera about the vertical axis only. `flip` is always false (the rig draws both facings). Runs split per frame while a character moves.
  - `lock.json`: `{ kit, lock_version, title, fps, frames, size, coords, places: [{ name, set, light, glb, meshes, materials, takes: [{ take, f0, f1 }] }], cards: [who], card_info: { who: { puppet, index, images, runs, height_m } }, sha1: { "camera_baked.json", "performance_baked.json" } }`. Re-export after every re-bake.
- **Placeholders, on purpose.** Moods are a colour wash and fx are a ring at the named prop: they show WHEN and WHERE, the look pass designs them. Unknown props are a lettered disc. Visibility is projection only (no occlusion). Set light is preview light.
- **Rig hooks still needed from the characters package.** Legs for a walk cycle; an arm layer in front of the head; shoulders and resting hands as data (now parsed from the arm path); hair exported apart from the face on forms; `stationmaster.props()` without its baked arm; blink and visemes on meme faces (a blink keeps the meme face today); side and back views of gestures.

## Added 2026-11-13 (ported from the fireworks crew test; CB "Yes, port them")
All new film.json keys are optional; a film without them renders pixel-identical to before (regression test 2026-11-13 on film_example, 6 frames, seeded dust: 0 px differ; unseeded dust in film.js differs a little between any two runs).
- `render.mjs --stills-dir <dir>`: write stills to a private folder, so parallel department renders never overwrite each other's `out/stills`.
- `render.mjs --hands <who>:<f0>-<f1>`: both hands of a card per frame in plan metres, plus the held3d grip and flame, to `out/plan/hands.json` (for vfx and lighting).
- `--animatic`: the voice is padded with silence (`apad`) so the film is never cut to the voice length (tested: 21.2 s video + 20.13 s voice = 21.2 s mp4).
- `"card_scale": { who: [[f, sx, sy], ...] }`: acted size change about the feet (puff, squash and stretch), smoothstep between keys.
- `"hand_at": [{ who, f0, f1, at: [x, y, z] }]`: the move hand lands on that plan point on this frame's card (hands end on things).
- `"held3d": [{ who, obj, module: "sets/<file>.js", builder: "buildLighter", behind, tilt }]`: a held prop is the set's own 3D model with a 3D ink fist round it, its grip anchor locked on the card hand every frame (the flat drawing is skipped). The builder returns `{ group, lid, flame, setLid, setFlame }`. `window.held3dDump(f)` and `window.heldGLTF()` export it for Blender.
- `"tween": { "ones": true }`: a new pose every frame instead of on twos.
- HEAD WOBBLE (CB_RULES 5): a 5-frame head-size pop (peak +7 %) on every face change. It fires only on motion-library poses (m:...) in films with "tween": { "frames": ... }, not on plain poses; `"tween": { "pop": 0 }` turns it off, `"faces_ep": { name: { ..., nopop: true } }` marks blink faces that do not pop.
- `"faces_ep": { name: {...} }`: episode faces built from kit face parts, used as `face: "k:<name>"`.
- `"costume_shade": { amount, start, cool }` (or per place light `costume_shade`): the costume, hat and cloth get a darker side away from the light; never the face (CB 2026-11-12 "exept for the face"). Optional `keep_drawn_light: true` (2026-11-15): every white / light-grey pixel of the drawing (face, its drawn crescent, a white animal like the hen) stays exactly as drawn; without it, the drawn crescent's outer part and white non-person cards get the costume ramp. Default off = old picture.
- Per station `"dof"` overrides the film's dof.
- Poses: `shrug` (shoulders up, one value or per hand) and a hand `behind: true` (that arm goes behind body and head).
- Cast specs with their own drawer: a `cast:` spec with `card = { metrics, svg(st, CARD) }` draws itself (a new body form such as an animal).
- `dump_decals.mjs`: the lock writes canvas decals white; run this in the episode folder to dump them as PNGs + `look/decals/DECALS.json` for the Blender layer pass.

## Added 2026-11-13, generic held 3D (props-hero, armor-no-holes fix round 2; backup of the kit before it: `_backup_2026-11-13_held3d/`)
ANY builder of an episode's `sets/<file>.js` can sit in a character's hand, with a 3D ink fist of the cast (round, thumb lobe, three creases across the shaft, soft shine: grips.mjs `wrapFist` in 3D) ON its grip anchor. A `held3d` entry WITH the key `"grip"` takes this path; an entry without it keeps the old lighter path, untouched. A film with no such entry renders pixel-identical to before (proof 2026-11-13: `film_example`, 26 frames, old kit against new kit with the page's `Math.random` seeded by the test harness, 0 pixels differ; all 5568 pose drawings of poses.mjs old against new, 0 different; `episodes/armor-no-holes/crew/props_hero2/regress/`).
```
"held3d": [{ "who": "chief", "obj": "lantern", "module": "sets/props.js", "builder": "buildLantern", "opts": {}, "grip": "hang", "hand": "L" }]
```
- The builder is any `(THREE, opts) -> { group, grip, ...anchors }` (anchors = THREE.Vector3, group-local). It is called once with `{ inHand: true, toon, ...opts }`. `"anchor"` names the hand point (default `grip`) or is `[x, y, z]`; `"tip"` names the working end (default `tip`); two-hand kinds use `"anchors": ["grip_left", "grip_right"]` (default; else the left and right middle of the bounding box).
- It shows while the card is visible and its baked state `prop` equals `obj` (`"when": "prop"`, default), or `"when": "always"`, or `"when": ["pose", ...]`; `f0` / `f1` narrow it. The flat placeholder prop and the flat grips.mjs object are not drawn then. The FIRST entry in the list that is on for a character and an object wins; two entries with different `"hand"` both stay (a paddle in each fist).
- Kinds: `pole` (upright in the fist, angle -84), `point` (points out to the hand's side, -12), `raise` (held up, -80), `hang` (hangs straight down from the fist: lantern, case, cap), `handle` (upright thing held by a side handle: mug, gun; `"flip_opts"` builds the mirrored object so its body is always on the inner / forward side and lettering faces the lens; `"face": "out"` turns a thing whose working end is its +X to the hand's side), `shoulder` (a long thing along the way the body faces: `"up": "+x"` = which local axis points up, `"lift"` degrees nose-up), `box` (ONE character, a fist on each side anchor; the object stands in front of the body turned as the body is turned, and both arms are solved to its anchors; `"pitch"`, `"yaw"`), `carry` (TWO characters, `"with": "<second>"`, four fists: the object lies level along the real line between them; `"roll"` tips its top face to the lens, `"spread"` = half the distance between one man's two fists; both must stand side-on to the lens, object length + 2 x 0.35 m apart).
- Angles are grips.mjs angles (screen degrees of the object's +Y, 0 = right, -90 = up, mirrored on the other side); `"angle"` may be keys `[[f, deg], ...]`. `"by_pose": { "<pose>": { "grip": ..., "angle": ..., "anchor": ..., "hand": ..., "mhand": 0 | 1 } }` changes the hold with the pose; in a pose in-between the object swings with it.
- `"tip_at": [{ "f0", "f1", "at": [x, y, z] | "<anchor of the place>", "ramp": [in, out] }]`: the tip lands ON that point. The fist is put one tip length from the point and the arm is solved to it at its fixed length (poses.mjs `state.hat`). Out of reach = the tip only aims; the gap is reported.
- `"hand_at": [{ who, hand: "R" | "L", f0, f1, at }]` now also works on PLAIN poses (only with `"hand"`; without it the old move-only behaviour).
- Depth: the prop and fist slide along the camera ray to just in front of the card (a far-hand hold of a side or 3/4 view: just behind it, the locked grip rule), so the 3D fist is seen exactly on the card's fist. An arm that cannot reach a two-hand anchor gets no fist there and the page warns once.
- Data: `window.held3dAll(f)` and `node render.mjs <film.json> --held <f,...> [--held-out <file>]` (default `out/plan/held3d.json`): grip, tip, every anchor of the builder, each fist in plan metres and on screen, `gap` in metres between arm end and fist (0 = locked). `window.held3dWorld(who, f)` answers with the same row. `window.handWorld` (`--hands`) now also gives plain-pose hands. `held3dDump` / `heldGLTF` carry the generic props (`generic: true`, `<key>:prop`, `:prop_flip`, `:fist`). Held groups are `noExport`.
- Other optional keys: `scale`, `fist` (fist size factor), `far` / `behind` (force the depth side / metres), `shadow: false`, `flame`, `level`, `lid`.
