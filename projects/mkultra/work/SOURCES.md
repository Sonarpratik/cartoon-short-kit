## Wording note for the user

The supplied line says “20,000 documents.” “About 20,000 pages of records” is a more careful description of the commonly cited collection, and primary sources describe differing page counts. Keep the original voice file untouched; flag the distinction at review. Do not add a 20,000-document label or portray the final rhetorical question as evidence of another specific destroyed program.
