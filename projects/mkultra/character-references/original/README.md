# MKUltra cast

The five original MKUltra designs are saved in `designs.json` and registered in the global `../cast.json` library: Civilian (seed 3), Researcher (5), Official (12), Investigator (9), and Archivist (6).

Their original project source, headwear, costume colours, moustaches, glasses, ties and pocket details are preserved here. `source-hashes.json` records the archived source. The project and finished movie are unchanged. The global studio uses these designs with the shared facial preferences and animation controls; it does not replace them with the Bootstrap inventor.

Open http://127.0.0.1:8787/?character=mkultra-civilian. Select another saved character in the sidebar to view it. Export or snapshot a selected MKUltra cast member for future projects in the same way as other library characters.
