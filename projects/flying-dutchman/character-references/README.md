# Project character references

Character designs, preserved renderer source and turnaround sheets live in this project. `original/` preserves the first saved design. Additional version folders retain revisions; the working scene imports its local source. The global Character Studio index lives in `character-library/cast.json`, outside the media references folder.

`current/` contains the latest corrected character renderer and designs; `v2/` and `motion-v3/` preserve earlier revisions. Active scene imports remain in `characters/`.
